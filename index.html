How to get your free TMDB key

ReelPick gets its movies, series and streaming info from TMDB, a free database. Each person uses their own free key, so nothing is paid and nothing is shared. It takes about two minutes, once.

  1. Create an account. Go to themoviedb.org/signup and confirm your email.
  2. Ask for an API key. Open Settings › API, choose to create a key for personal (non-commercial) use, accept the terms and fill in the short form (any app name, e.g. “ReelPick”, and a one-line description).
  3. Copy the token. On that same page, copy the long API Read Access Token. (The short “API Key” also works.)
  4. Paste it here. Click TMDB key… at the bottom of this page, paste it and press Save. The demo banner disappears and the platform logos for your country show up.

Your key stays in this browser only and is sent only to TMDB. Never put it in a public file or share a screenshot of it.

How to use it

  1. Pick Movies, Series or Both.
  2. Tick the genres you fancy (none = any). “Must match all” keeps only titles with every selected genre.
  3. Choose your country, then tap the streaming platforms you have. Only titles included in those subscriptions are picked.
  4. Choose a style (hidden gems, classics, recent…) and a minimum rating if you want.
  5. Press SPIN or pull the lever. The reel slows down on a random title.
  6. Not into it? Seen it — spin again remembers it and never shows it again (manage it in “My seen list” in the footer).

No key yet? The page works in demo mode with a small built-in sample, without platform filters.

This product uses the TMDB API but is not endorsed or certified by TMDB. Streaming availability data provided by JustWatch via TMDB.
